# 小管家 H5（V1.0.2）

依据 [001.产品PRD/个人财务管理产品PRD.md](../001.产品PRD/个人财务管理产品PRD.md) 开发的记账 Web 应用。
纯 HTML/CSS/原生 JS，无构建步骤、无第三方依赖、无服务端。

## 运行方式

方式一（推荐，完整 PWA 体验）——任意静态服务器，在 `002.小管家H5` 目录下：

```bash
python -m http.server 8080
# 或 npx serve .
```

然后手机/电脑浏览器访问 http://localhost:8080 。

方式二：直接双击 `index.html` 用浏览器打开（功能完整；Service Worker 在 file:// 下不生效，离线缓存与「添加到主屏幕」需用方式一）。

## 功能清单（对应 PRD 第四章 P0）

| 功能 | 说明 |
| --- | --- |
| 记一笔 | 支出/收入切换、金额校验（>0、两位小数、上限 99,999,999）、分类默认上次使用、账户默认现金、日期不可选未来、备注 ≤50 字；支持「再记一笔」连续记账 |
| 账单明细 | 按日分组 + 当日小计、当月汇总卡、筛选（类型/分类/账户/备注关键词/自定义时间范围）、点击编辑、软删除进回收站、分页加载 |
| 分类管理 | 预置 9 支出 + 5 收入，新增/重命名/排序/停用（不物理删除），历史账单不受影响 |
| 统计报表 | 月度总览（环比涨跌）、分类占比条形（点击跳转明细）、每日支出柱状（周末高亮 + 表格视图）、近 6 个月折线（crosshair + 表格视图），可切换月份 |
| 预算 | 月度总预算、预算进度 meter、日均可用、80%/100% 各提醒一次（每月每档一次）、预算 Tab 红点 |
| 数据 | localStorage 本地存储（金额以「分」为整数）、回收站保留 30 天、CSV 导出（UTF-8 带 BOM，Excel 中文不乱码）、清空数据双重确认、持久化存储申请 |
| 注册登录（V1.0.1） | 本机账户锁（PRD 4.7）：注册 / 登录、7 天免登录、连错 5 次锁 5 分钟、退出登录、数据按账户隔离、V1.0 旧数据自动迁移；密码加盐哈希存储，**忘记密码无法找回**（云端账号随 V2.0） |
| 供应商 & 图片（V1.0.2） | 供应商可选字段（PRD 4.8）：记账自动补全、新名称自动创建、明细筛选、统计 Top5 排行、独立管理页；图片上传（PRD 4.9）：每笔 ≤5 张，自动压缩（最长边 1280px、目标单张 ≤200KB）与账单分开存储，点缩略图全屏预览 |
| PWA | manifest + Service Worker 离线缓存，支持添加到主屏幕 |

## 工程结构

```
002.小管家H5/
├── index.html            页面骨架（4 Tab + 悬浮记账按钮 + 通用弹层）
├── css/style.css         设计令牌与组件样式（图表配色取自 dataviz 参考调色板）
├── js/store.js           数据层：localStorage、软删除、统计口径、CSV
├── js/charts.js          图表层：分类占比条、每日柱状、6 月折线（纯 SVG + tooltip）
├── js/auth.js            本机账户锁：注册/登录/免登录/锁定（V1.0.1）
├── js/app.js             UI 层：视图渲染、弹层、筛选、预算预警
├── manifest.webmanifest  PWA 清单
├── sw.js                 离线缓存（cache-first）
└── icon.svg              应用图标
```

## V1 已知取舍（与 PRD 风险表对应）

- 浅色模式（深色模式列入后续迭代）；分类/账户排序用 ↑↓ 按钮，拖拽排序后续再上。
- 本机账户锁不是云端账号：忘记密码无法找回（注册页已明示），修改密码列入 V1.1。
- H5 本地存储有被浏览器清理的风险：已做持久化存储申请 + 引导 CSV 导出，云同步在 V2.0。
- PWA 推送提醒在部分平台受限：V1 用页面内提示 + 预算 Tab 红点兜底。
